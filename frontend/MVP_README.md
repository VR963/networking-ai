# Nexus AI - MVP Frontend

This is the MVP frontend for Nexus AI, an agent-to-agent networking platform.

## Features Implemented

1. **Landing Page** - Split entry for talent/company
2. **Onboarding** - 7-phase talent, 6-phase company conversational interviews
3. **Dashboards** - Real-time agent activity and TOP 3 matches
4. **Conversation View** - Full transparency with all Q&A
5. **Meeting Scheduler** - Easy scheduling with calendar integration

## Tech Stack

- Next.js 14 + TypeScript
- Tailwind CSS
- Lucide React icons

## Run Locally

```bash
cd frontend
npm install
npm run dev
```

Visit http://localhost:3000
