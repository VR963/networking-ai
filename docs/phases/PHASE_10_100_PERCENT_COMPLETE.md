## Deployment Guide

### Prerequisites

```bash
# 1. Server Requirements
- Python 3.11+
- PostgreSQL 14+
- Redis 6+ (for production rate limiting)
- 2GB+ RAM
- 2+ CPU cores

# 2. Environment Variables
DATABASE_URL=postgresql://user:pass@localhost/networking_ai
JWT_SECRET_KEY=<strong-random-key-256-bits>
JWT_ALGORITHM=HS256
REDIS_URL=redis://localhost:6379
```

### Deployment Steps

```bash
# 1. Clone repository
git clone https://github.com/yourorg/networking-ai.git
cd networking-ai

# 2. Install dependencies
pip install -r requirements.txt

# 3. Run database migrations
alembic upgrade head

# 4. Create database indexes (see PERFORMANCE_TESTING_GUIDE.md)
psql -d networking_ai -f scripts/create_indexes.sql

# 5. Configure security headers
# Add middleware from SECURITY_AUDIT_REPORT.md

# 6. Configure production CORS
# Update main.py with production domains

# 7. Setup Redis rate limiting
# Implement Redis rate limiter (see SECURITY_AUDIT_REPORT.md)

# 8. Run tests
pytest tests/ -v

# 9. Start application
uvicorn src.networking_ai.api.main:app --host 0.0.0.0 --port 8000 --workers 4

# 10. Verify health
curl http://localhost:8000/api/health
```

### Production Configuration

**Recommended Setup**:
- **Load Balancer**: Nginx/HAProxy
- **App Servers**: 2-4 Gunicorn workers with 4 threads each
- **Database**: PostgreSQL with read replicas
- **Cache**: Redis cluster
- **Monitoring**: Prometheus + Grafana
- **Logging**: ELK stack or CloudWatch
