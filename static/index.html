🔌 REST API Endpoints

Full-featured REST API with 25+ endpoints covering authentication, onboarding, matching, messaging, marketplace, and more. Note: These are programmatic endpoints for apps, not web pages.

📋 API Endpoint Categories:

  • POST /api/auth/login - User authentication
  • POST /api/registration/register - User registration
  • GET /api/onboarding/status - Check onboarding progress
  • GET /api/agents/me - Get user's AI agent
  • POST /api/matching/find-matches - Find job/candidate matches
  • GET /api/conversations - List conversations
  • GET /api/v1/marketplace/agents - Browse marketplace

💡 Tip: Use the interactive API documentation below to test endpoints with authentication.

🚀 Quick Start Guide

Option 1: Interactive Documentation (Easiest)

Click the "Swagger UI (Interactive)" button above to access the full API documentation with a built-in testing interface. You can authenticate and test all endpoints directly in your browser!

Option 2: Command Line (Mac Terminal)

Test the API from your Mac terminal:

# Check API health
curl http://localhost:8000/api/health

# Register a new user (example)
curl -X POST http://localhost:8000/api/registration/register \
  -H "Content-Type: application/json" \
  -d '{"email": "user@example.com", "password": "securepass123", "user_type": "talent"}'

# Login (after registration)
curl -X POST http://localhost:8000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email": "user@example.com", "password": "securepass123"}'

Option 3: Build Your Own Client

This is a REST API backend. You can build:

  • Web frontend (React, Vue, Angular)
  • Mobile app (iOS, Android, React Native)
  • Desktop application
  • Integration with existing systems
